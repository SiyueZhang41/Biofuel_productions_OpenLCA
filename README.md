## This project aims to perform LCA of biofuel productions using OpenLCA from Python and EcoInvent database

The data was obtained from the database EcoInvent and from the work of Su et al. [Su, C.-L., & Lee, Y.-M. (2009). Development status and life cycle inventory analysis of biofuels in Taiwan. Energy Policy, 37(2), 754–758. https://doi.org/10.1016/j.enpol.2008.09.076]

The code is presented in the notebook Biofuels.ipynb.

All the data processing and management is performed in python, and the calculations are performed using OpenLCA, through the python API.
Analysis of the results is performed in python.
